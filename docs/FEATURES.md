# S.O.N.A.R. Crew Toolkit — feature reference

S.O.N.A.R. Crew Toolkit focuses on three connected areas: crew planning, session records, control reference. Its organization keeps frequently used options close to the context they belong to.

| Section | Description |
|---|---|
| Crew planning | Character or team groups presented with the context needed to organize a session. |
| Session records | Session and activity information grouped by the task or context it belongs to. |
| Control reference | A dedicated section for control reference and the configuration details associated with that area. |

The project page follows the same section structure.
